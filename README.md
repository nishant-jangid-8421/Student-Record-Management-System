# Student Record Management System

I developed this project using C programming to manage student records with a Singly Linked List.

### Features
- Add and display student records
- Delete and modify records
- Sort records by name and percentage
- Reverse the linked list
- Save and load records using file handling
- Automatic roll number generation

### Concepts Used
C Programming, Structures, Pointers, Singly Linked List, Dynamic Memory Allocation and File Handling.

### Compilation
```bash
make
```

### Execution
```bash
./student
```
